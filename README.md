# Poohkao

I build practical tools and learn by shipping. My interests span calm interfaces,
local-first applications, and the systems underneath them.

## Building Daybreak

[Daybreak Study Planner](https://github.com/Poohkao2026-beep/Daybreak-study-planner)
is a calm, local-first study planner for choosing the next task, protecting focus
time, and reviewing progress. AI study support is optional and consent-based.

[Try the planner](https://daybreak-study-planner.vercel.app/planner) ·
[Preview guide](https://github.com/Poohkao2026-beep/Daybreak-study-planner/blob/main/packages/planner-launcher/README.md)

## Technologies and interests

- Systems exploration: [Main1PeakPulseOrogenyCore](https://github.com/Poohkao2026-beep/Main1PeakPulseOrogenyCore), a lock-free MPMC ring buffer and telemetry engine.

## Engineering principles

- Keep core workflows useful offline and make data recovery straightforward.
- Make consent and data boundaries visible.
- Favor small changes, clear interfaces, and checks that exercise real behavior.
- Treat accessibility, readable code, and predictable failure as part of the design.
